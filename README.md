# [Ism Familiya] — Shaxsiy veb-sayt

Buxgalter va moliyachi uchun shaxsiy veb-sayt. O'zbek tilida, rasmiy va
ishonchli uslubda, telefon va kompyuterda birdek ochiladigan responsive sayt.

## 📁 Fayllar

```
├── index.html         # Asosiy sahifa (barcha bo'limlar)
├── cv.html            # CV sahifasi — "PDF sifatida saqlash" tugmasi bilan
├── css/style.css      # Barcha dizayn va uslublar
├── js/main.js         # Menyu, statistika animatsiyasi, scroll effektlari
├── blog/
│   └── maqola-1.html  # Namuna blog maqolasi
├── assets/img/        # Suratlar va favicon (photo.jpg ni shu yerga qo'ying)
└── REJA.md            # Loyiha rejasi
```

## ✏️ Qanday to'ldirish kerak

Barcha o'zgartirish kerak bo'lgan joylar `[kvadrat qavs]` ichida belgilangan.
Ularni qidirib, o'z ma'lumotingiz bilan almashtiring:

- **`[Ism Familiya]`** — ismingiz (bir necha faylda uchraydi)
- **`[IF]`** — ism-familiya bosh harflari (logo/favicon)
- **Telefon / email / Telegram** — `index.html` va `cv.html` dagi bog'lanish qismida
- **Surat** — professional foto'ni `assets/img/photo.jpg` sifatida joylashtiring
- **Ish tajribasi, xizmatlar, loyihalar, statistika** — mos bo'limlardagi matnlar

## 🖼️ Surat qo'shish

`assets/img/` papkasiga `photo.jpg` nomli surat qo'ying. Surat bo'lmasa,
o'rniga "[Sizning suratingiz]" yozuvi ko'rinadi (sayt buzilmaydi).

## 📄 CV (PDF)

`cv.html` sahifasini brauzerda oching va **"PDF sifatida saqlash"** tugmasini
bosing — brauzer chop etish oynasida "Save as PDF" ni tanlang. Tayyor PDF
faylingiz bo'lsa, uni `assets/cv.pdf` ga qo'yib, havolalarni o'zgartiring.

## 🌐 Joylashtirish (GitHub Pages — bepul bitta havola)

1. GitHub'da repozitoriy sozlamalariga kiring: **Settings → Pages**
2. **Source** bo'limida `Deploy from a branch` ni tanlang
3. Branch: `main` (yoki joriy branch), papka: `/ (root)` → **Save**
4. Bir-ikki daqiqada saytingiz `https://<username>.github.io/meningsaytim/`
   havolasida ochiladi — istalgan odam telefon yoki kompyuterda ocha oladi.

Keyinchalik shaxsiy domen (masalan `ismfamiliya.uz`) ham ulash mumkin.
